# Code of Conduct

This project follows a concise, project-specific code of conduct informed by the **Contributor Covenant, version 2.1**. The [full Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) provides the reference standard.

This expectation applies to project issues, pull requests, discussions, and other project spaces. Participants should be respectful, constructive, and welcoming. Harassment, discrimination, personal attacks, deliberate intimidation, and publishing another person's private information are not acceptable.

Project maintainers are responsible for clarifying and enforcing these expectations. They may remove or edit unacceptable content, close contributions, or temporarily or permanently exclude a participant from project spaces, with an explanation of the action taken.

For a conduct concern, contact the maintainer privately through the [repository owner's GitHub profile](https://github.com/professionaltarun2004). Do not include sensitive details in a public issue. The repository does not publish a separate private email address.
