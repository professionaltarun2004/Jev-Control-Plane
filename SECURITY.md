# Security policy

## Supported versions

The project has not declared a version support policy. Until maintainers designate supported releases, report issues against the current default branch. No response time is promised.

## Reporting a vulnerability

Please do not publish exploit details, credentials, or sensitive traces in a public issue or pull request.

If GitHub's private vulnerability reporting is enabled for this repository, use its **Report a vulnerability** flow. This repository does not publish a dedicated security email address. If private reporting is unavailable, use the maintainer contact route on the [repository owner's GitHub profile](https://github.com/professionaltarun2004) to request a private channel without posting technical details publicly.

If a TypeSafe API key may have been exposed, revoke or rotate it through the provider immediately. Removing a key from the latest file or commit does not remove it from Git history; report the exposure so maintainers can assess history and coordinate remediation.
